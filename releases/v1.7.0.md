# v1.7.0 — `--all` lean passthrough mode

New `--all` CLI flag (also auto-detected when `MCP_URL` path ends in `/mcp/all` or `/all`, or via `MCP_ALL_MODE=1`) for mcpproxy-go's `/mcp/all` endpoint: the shim becomes a thin forwarder, surfacing upstream tools verbatim with their native `inputSchema` and skipping shim-local `describe_tools` / `proxy_admin` injection and the BM25 wrap.

Default `/mcp/` behavior is **unchanged** — `call_tool_*` schema rewrite, shim-local tools, and dynamic discovery still work as before. Trade-off documented in README *Why Not `/mcp/all`?*: `--all` gives you native schemas at the cost of a frozen-at-connect-time tool list.
